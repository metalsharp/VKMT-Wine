# VKMT third-party licenses

VKMT is an integration of upstream projects. The runtime and source snapshot
retain the applicable notices and license texts for Wine, FEX/FEXCore, DXMT,
DXVK, VKD3D-Proton, MoltenVK, innoextract, Wine Mono, and MetalSharp-owned
compatibility code.

For the complete release-side index, see
source/third-party-licenses/README.md and the license files beside it. The
release archive also retains component notices where the upstream package
requires them.

No single project-wide license is inferred for third-party components. Review
the included notices before redistribution.
